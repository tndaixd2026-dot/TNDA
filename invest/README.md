# 期末提報「即時投資」互動系統

需求規格見專案根目錄的 [`SPEC.md`](../SPEC.md)。這是一個獨立的子專案，和根目錄的 TNDA Relay 互不影響。

| 網址 | 給誰用 |
|---|---|
| `/` | 學生端（手機優先）：輸入姓名登入，像買賣股票一樣分配 100 萬 |
| `/screen` | 現場大螢幕（65 吋橫式）：走勢圖＋排行 → 暗盤倒數 → 結果揭曉 |
| `/screen?course=wed` | 固定顯示上半場（`thu` 為下半場），不跟著管理員切換 |
| `/admin` | 管理員：切換場次、開盤／暗盤／封盤、看誰還沒投完、匯入名單、重置 |

## 架構

- **一個 Node 程序**同時提供 API、即時推播與前端網頁，沒有資料庫：狀態在記憶體裡，每次變動後寫入 `DATA_DIR/state.json`，重啟會自動還原（包括進行中的暗盤倒數）。
- **即時同步**用 Server-Sent Events：學生下單後，伺服器在 150 毫秒內把新狀態推給所有裝置（規格要求 2 秒內）。手機休眠、斷線後會自動重連。
- **所有規則都在伺服器端驗證**（`shared/rules.ts` + `server/store.ts`）：不能投自己、單組 50 萬上限、餘額、開封盤時間。前端只做提示。
- **暗盤保密**：暗盤期間伺服器送出的公開資料裡沒有各組金額、排名，也不送暗盤後的走勢；學生只拿得到自己的投資。封盤後才揭曉完整走勢與結果。
- 只能跑**單一個執行個體**（狀態在記憶體），不要開多台水平擴充。約 50 人同時在線綽綽有餘（實測 50 條連線、每秒 230 筆下單無錯誤）。

```
shared/   規則、結算、名單解析（前後端共用、純函式）
server/   HTTP + SSE（app.ts）、狀態與存檔（store.ts）、進入點（main.ts）、假名單（seed.ts）
src/      前端（Preact）：pages/Student、Screen、Admin
tests/    規則、名單解析、伺服器端對端測試
```

## 本機開發

需要 Node.js 22.18 以上。

```bash
cd invest
npm install
npm run dev          # API :8787 + Vite 前端 :5173（預設管理員密碼 admin）
npm test             # 單元與端對端測試
npm run typecheck
```

## 正式啟動

```bash
npm ci
npm run build
ADMIN_PASSWORD='換成你的密碼' npm start
```

| 環境變數 | 預設 | 說明 |
|---|---|---|
| `ADMIN_PASSWORD` | 開發模式為 `admin` | 管理員密碼，可以是中文。`NODE_ENV=production` 時沒設定會拒絕啟動 |
| `PORT` | `8787` | |
| `HOST` | `0.0.0.0` | |
| `DATA_DIR` | `./data` | 存放 `state.json` 的目錄，要放在重啟後不會消失的地方 |
| `DARK_SECONDS` | `300` | 暗盤長度（秒）。彩排時可以設短一點，例如 `30` |

## 部署（讓現場手機連得到）

任何能長時間跑一個 Node 程序、支援串流回應的地方都可以。兩種建議做法：

**A. 雲端主機（Render、Zeabur、Fly.io、Railway 等）**
用本目錄的 `Dockerfile`，或設定：根目錄 `invest`、建置指令 `npm ci && npm run build`、啟動指令 `npm start`。
要設定 `ADMIN_PASSWORD`，並把 `DATA_DIR` 指到**持久化磁碟**；免費方案通常沒有持久化磁碟，而且閒置會休眠（重啟會清空資料、第一個連線要等很久），活動當天建議用付費方案或至少提前喚醒。

**B. 現場筆電 + Cloudflare Tunnel（免費、資料留在自己電腦）**
```bash
ADMIN_PASSWORD='…' npm start
cloudflared tunnel --url http://localhost:8787   # 會給一個 https://xxxx.trycloudflare.com 公開網址
```
啟動時終端機也會印出區網網址（`http://192.168.x.x:8787`），若手機和筆電在同一個 Wi-Fi 也能直接連。

大螢幕的 QR code 會自動使用大螢幕當下開啟的網址，所以請用公開網址開 `/screen`。

## 活動當天流程

1. **事前**：管理員頁 → 名單 → 匯入正式名單 CSV，展開檢查兩堂課的組別與人數。
2. **彩排**：開盤 → 用幾支手機下單 → 進入暗盤 → 立即封盤，確認大螢幕與手機都正常 → 「重置」該場。
3. **上半場**：場次選「上半場・週三」→ 學生掃大螢幕 QR code 登入 → 開盤 → 報告進行中 → 封盤前 5 分鐘按「進入暗盤」→ 倒數結束自動封盤，大螢幕揭曉結果（備用：「立即封盤」）。
4. 管理員頁「下載結果 CSV」留存。
5. **下半場**：場次切到「下半場・週四」，重複步驟 3、4。上半場的結果會保留，學生端也看得到自己上半場的成績。

管理員頁的「還沒投完」清單可以在暗盤前提醒還有餘額的同學（標示「會倒扣」的是有登入的人）。誤按封盤時可按「取消封盤」。

## 名單

CSV 每行「姓名, 課堂, 組別」，第一行標題可有可無；課堂填 `週三`／`週四`（也接受 `三`、`上半場`、`wed` 等）。可以上傳檔案，或從 Google 試算表直接複製貼上（Tab 分隔）。

```
姓名,課堂,組別
王小明,週三,第1組
王小明,週四,第3組
```

- 同一人修兩堂課就寫兩行，兩堂課的組別可以不同；兩堂課的 100 萬互不相通。
- 匯入只會取代 CSV 裡有出現的課堂，另一堂不受影響。已封盤的場次要先重置才能改名單。
- 開盤中也可以匯入（例如臨時補人）；預覽會列出因為換組或被移除而退回的投資。
- 組別寫成「第2組：看到太陽就知道完蛋了」時，畫面會顯示「第2組」加上組名。
- 還沒匯入時使用 `server/seed.ts` 的假名單（週三 20 人 5 組、週四 28 人 7 組，其中 10 人兩堂都有），方便彩排。正式名單含真實姓名，**不要提交到 git**，請由管理員頁匯入。

## 已確認的規則細節

規格沒寫明的地方，以下是和老師確認過的做法：

1. **缺席、沒登入的同學不倒扣**。只有「這一場有登入過」的人，封盤時沒投完的錢才會從自己那組倒扣。登入過 = 這一場進行時開過學生頁（含切換場次時頁面還開著）或有下單。彩排後按「重置」會清掉出席紀錄。
2. **結果排行榜只列各組**：投資總額、倒扣、最終金額、倍率，不列學生姓名。股神獎只顯示得獎者。含姓名的完整明細只在管理員的「下載結果 CSV」。
3. **金額最小單位 1 元**。學生端可以直接輸入以「萬」為單位、小數點後最多 4 位的金額（例如 12.3456 萬 = 123,456 元），畫面也精確顯示到 1 元。
4. **最高的組即使是負數，一樣拿一飛沖天獎**；同分並列。
5. **個人名次的分母只算有投資的人**；沒投資的人不列入個人排名（學生端會顯示「你這一場沒有投資」）。這一場沒有人投資時，股神獎從缺。
6. **不加個人代碼**，現場只輸入姓名登入（規格 11）。代價是知道別人姓名就能看到對方的投資，已知並接受。
7. **可以取消封盤**（誤按時用）：管理員頁「取消封盤」會撤回結果、保留所有投資。暗盤中手動封盤、倒數還沒結束 → 回到暗盤接續剩下的倒數；其他情況 → 回到開盤中。
8. **名單**：Notion「學生名單｜互動兩堂課」，週三＝115-1 VSAI（用「W9 分組」，5 組），週四＝115-1 跨域數位製作實務（用「115-1 跨域分組」，7 組）；期中棄選的同學排除；組名照 Notion 原文顯示。
9. **管理員密碼**由部署時的 `ADMIN_PASSWORD` 設定，可以是中文（例如老師的姓名）。密碼不寫進程式碼與 git。

## 其他實作細節

- 學生只認姓名：前後空白、全形半形、英文大小寫視為同一人。
- 走勢圖顯示各組「收到的投資總額」（階梯線：交易當下才跳動），封盤那一刻跳到含倒扣的最終金額；暗盤期間的走勢在封盤後才補上並以底色標示。
- 按「＋」會超過 50 萬上限或餘額不足時直接擋下並提示，不會自動調整金額。
